# Backend Engineer — Stripe (synthetic verification brief)

This sample is a fictionalized test brief for an interview at the named company; it is not an active Stripe job posting.

## Role

Build dependable backend services for payment and financial infrastructure. Work with product, risk, and infrastructure teams to deliver APIs and event-driven systems that remain correct under retries, concurrency, and partial failures.

## Requirements

- 3+ years building production backend services in Python, Go, Java, or a similar language.
- Strong knowledge of distributed systems, message delivery semantics, idempotency, retries, and consistency.
- Experience with relational databases, schema evolution, query tuning, and transactional correctness.
- Design and operate highly available APIs and asynchronous workers; define useful SLOs and respond to production incidents.
- Familiarity with payment lifecycles, ledger or reconciliation concepts, fraud/risk controls, and secure handling of sensitive data.
- Experience with observability, automated testing, code review, and cloud deployment practices.

## Interview focus

Expect discussion of a system the candidate owned, correctness under duplicate/out-of-order events, database trade-offs, incident response, and how they would learn a domain gap such as payment ledgers or risk controls.
