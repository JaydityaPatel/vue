# Application workspace

This directory contains the FastAPI backend, React frontend, standalone orb demo, and project scripts. The repository root README is the main setup guide; start there for Windows setup, RTX 3050/CUDA notes, run commands, and tests.

The project currently includes Phases 1-8: authentication and interview pages, adaptive interview planning and reports, voice practice, Resume and Job modes, a spoken introduction for document sessions, and optional Job-mode web research.

Phase-specific implementation notes are in [backend/PHASE4.md](backend/PHASE4.md), [backend/PHASE5.md](backend/PHASE5.md), [backend/PHASE6.md](backend/PHASE6.md), [backend/PHASE7.md](backend/PHASE7.md), and [backend/PHASE8.md](backend/PHASE8.md).
